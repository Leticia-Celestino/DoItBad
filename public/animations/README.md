# Intro Rive

- Fonte: `rive-intro/scene.rml`.
- Arquivo servido: `intro.riv`; runtime local: `rive.wasm`.
- Artboards: `Intro` (desktop) e `IntroMobile` (retrato).
- State machine: `Intro`; timeline: `IntroTimeline`, 276 frames a 60 fps.
- Marca fixa centralizada, descoberta pela cortina que acompanha a caminhada.
- O chute afasta a cortina; o personagem sai e resta apenas a marca.
- Reprodução: `/pt-br/?intro=1`, respeitando movimento reduzido.

Contrato e direção visual: `docs/INTRO-RIVE-IMPORT.md`.
