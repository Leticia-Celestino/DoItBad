# Próxima missão — beta DoItBad universal

## Objetivo

Transformar a versão beta em um aplicativo utilizável para estudos de francês, usando
`../doitbad_app_design` como referência visual e funcional para mobile e desktop web em tela cheia.

## Direção do produto

- Mobile focado em um passo por vez, timer, intenção e retomada.
- Desktop com dashboard amplo, sidebar, histórico, mapa de execução e estatísticas.
- Mesma conta, dados e progresso sincronizados entre dispositivos via Supabase.
- Primeira experiência de uso direcionada a sessões de estudo de francês.

## Primeira entrega

1. Consolidar tokens e componentes do design de referência.
2. Adaptar onboarding, login e fluxo de foco para desktop responsivo.
3. Conectar tarefas, intenções, timer e histórico ao Supabase.
4. Criar modo de estudo de francês sem quebrar o fluxo genérico.
5. Validar a experiência em celular, tablet e desktop.

Esta missão fica como prioridade após a validação manual das duas contas do beta atual.
